# Contribuer
- à AppCommon v1.0

> Merci de votre intérêt pour AppCommon.

### Signaler un bug
Ouvrez un ticket avec :
- Description du problème
- Étapes pour reproduire
- Environnement

### Proposer une fonctionnalité
Expliquez :
- Le besoin
- L’impact
- La solution envisagée

### Pull Requests
- Code propre
- Commentaires utiles
- Tests si nécessaire
