AppCommon v1.0 — Documentation

Bienvenue dans la documentation officielle d’AppCommon v1.0.  
Ce dossier contient l’ensemble des guides, références techniques et informations nécessaires pour comprendre, utiliser, étendre et maintenir le template AppCommon.

AppCommon v1.0 est un template universel, minimaliste, propre et extensible, conçu pour servir de base à n’importe quel projet web ou application front‑end.

---

📚 Table des documents

La documentation est organisée en plusieurs sections :

1. Structure générale
- usage.md — Comment utiliser AppCommon v1.0, workflow de base, structure du projet.
- extend.md — Comment étendre AppCommon : frameworks, bundlers, modules, manifest, icônes, build avancé.

2. Références techniques
- html.md — Structure HTML, bonnes pratiques, meta tags, Open Graph, manifest, favicons.
- css.md — Base CSS AppCommon, typographie, reset léger, classes utilitaires, autoprefixer.
- js.md — Organisation du JavaScript, modules, vendor, intégration avec bundlers.

3. Fichiers complémentaires
- misc.md — .gitignore, .editorconfig, robots.txt, package.json.
- faq.md — Questions fréquentes sur AppCommon v1.0.

4. Contribution & gouvernance
- CONTRIBUTING.md — Comment contribuer au projet.
- CODEOFCONDUCT.md — Code de conduite.
- ISSUE_TEMPLATE.md — Modèle pour les tickets.
- PULLREQUESTTEMPLATE.md — Modèle pour les PR.
- SUPPORT.md — Ressources d’aide.

---

🧱 Objectifs de la documentation

La documentation AppCommon v1.0 vise à :

- fournir une base claire et compréhensible pour tous les utilisateurs  
- permettre une extension facile du template  
- offrir des guides pratiques pour les développeurs débutants ou avancés  
- documenter les bonnes pratiques front‑end modernes  
- centraliser toutes les informations techniques du projet

🚀 Comment utiliser cette documentation

1. Commence par usage.md pour comprendre la structure du projet.  
2. Lis html.md, css.md, js.md pour maîtriser les bases techniques.  
3. Consulte extend.md si tu veux ajouter un framework, un bundler ou des modules.  
4. Réfère-toi à misc.md pour les fichiers système et de configuration.  
5. Utilise faq.md pour les questions courantes.  
6. Si tu contribues, lis CONTRIBUTING.md et les modèles de PR/Issues.

🛡️ Philosophie AppCommon

AppCommon v1.0 est conçu pour être :

- minimaliste  
- modulaire  
- extensible  
- non‑intrusif  
- compatible avec tout  

Tu peux :

- ajouter  
- remplacer  
- supprimer  
- réorganiser  
- reconstruire  

AppCommon est un point de départ, pas une destination.
