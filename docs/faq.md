# AppCommon v1.0 — Foire Aux Questions (FAQ)

[AppCommon v1.0 — Accueil](../README.md)  
[Documentation — Table des matières](TOC.md)

Cette FAQ répond aux questions les plus courantes concernant AppCommon v1.0, son utilisation, ses mises à jour et son support.

---

## Dois‑je mettre à jour mon projet à chaque nouvelle version d’AppCommon ?

Non.

AppCommon v1.0 est conçu comme une **fondation stable**, exactement comme les fondations d’un bâtiment :  
une fois en place, vous n’avez pas besoin de les remplacer à chaque nouvelle version.

Cependant :

- vous pouvez intégrer les nouveautés si elles vous intéressent  
- vous pouvez adapter votre projet aux évolutions  
- vous pouvez migrer vers une version supérieure si cela apporte un bénéfice réel  

AppCommon est un **point de départ**, pas une contrainte.  
Vous décidez si une mise à jour vaut la peine.

---

## Où puis‑je obtenir de l’aide ou du support ?

Pour des questions techniques générales (HTML, CSS, JS, Gulp, npm, etc.), vous pouvez utiliser :

- **Stack Overflow**  
- **Forums de développement web**  
- **Communautés JavaScript / Front‑end**

AppCommon étant un template universel, la plupart des questions relèvent de pratiques front‑end standard.

---

## AppCommon v1.0 convient‑il aux frameworks modernes ?

Oui.

AppCommon peut être utilisé avec :

- React  
- Vue  
- Svelte  
- Angular  
- Astro  
- Next.js / Nuxt  
- Webpack / Vite / Parcel / Rollup  

Il est volontairement minimal pour être compatible avec n’importe quel environnement.

---

## Puis‑je supprimer des fichiers ou dossiers ?

Oui.

AppCommon est conçu pour être **modulaire** :

- supprime ce que tu n’utilises pas  
- ajoute ce dont tu as besoin  
- remplace les fichiers par tes propres versions  

Tu peux même réduire AppCommon à un simple `index.html` si tu veux.

---

## AppCommon v1.0 inclut‑il un système de build obligatoire ?

Non.

Le système Gulp fourni est :

- minimal  
- optionnel  
- facilement remplaçable  

Tu peux utiliser :

- Webpack  
- Vite  
- Parcel  
- Rollup  
- ou aucun système de build du tout

---

## AppCommon v1.0 est‑il adapté aux projets professionnels ?

Oui.

Il est conçu pour :

- prototypes  
- sites statiques  
- applications front‑end  
- projets éducatifs  
- bases de projets professionnels  
- environnements modulaires personnalisés  

Sa simplicité est un avantage : tu construis exactement ce dont tu as besoin.

---

## Puis‑je utiliser AppCommon pour un projet commercial ?

Oui.

AppCommon v1.0 utilise **The Unlicense**, ce qui signifie :

- usage libre  
- modification libre  
- distribution libre  
- usage commercial autorisé  
- aucune restriction  

Tu peux l’utiliser pour n’importe quel type de projet.

---

## Conclusion

AppCommon v1.0 est un template universel, stable et flexible.  
Tu n’es jamais obligé de le mettre à jour, tu peux l’adapter librement, et tu peux l’utiliser dans n’importe quel contexte — personnel, professionnel ou commercial.
